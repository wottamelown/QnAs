# Q-As

-- Common Protocols With Port Numbers --

Port 22: SSH, SFTP (Encrypted).
Port 23: TelNet (Unencrypted).
Port 24: SMTP (Simple Mail Transfer Protocol) - Server 2 Server Maiil Tranfer - TCP)
Port 587: SMTP (Encrypted)
Port 53: DNS (Domain Name System) - UDP 
Port 67,68: DHCP (Dynamic Host Configuration Protocol) - UDP
Port 69: TFTP (Trivial File Transfer Protocol) - UDP - Cisco Phones DHCP op 150 or 66 to retrieve the IP address & file of the CUCM server. 
Port 80: HTTP (Hyper Text Transfer Protocol) - TCP 
Port 443: HTTPs (Hyper Text Transfer Protocol Secure) - TCP - SSL/TLS
Port 123: NTP (Network Time Protocol) - UDP - Keeps clock in sync across all devices. 
Port 161: SNMP (Simple Network Management Protocol) - UDP - Gather Stats from Network Devices. 
Port 389: LDAP (LightWeight Discovery Access Protocol) - UDP - Query User Databases
Port 636: LDAPs (LightWeight Discovery Access Protocol Secure) - TCP - Uses SSL encryption to query. 
Port 445: SMB (Server Message Block) - TCP - Microsoft File Sharing & Printer Sharing. 
Port 514: Syslog - UDP - Used in SIEM, Central Logging to collect logs in one area. 
Port 1433: MSSQL DB - TCP - used by MS SQL Server for DB connections. 
Port 3389: RDP (Remote Desktop Protocol) - TCP - Microsoft native desktop initiation protocol. 
Port 5060,5061: VoIP - TCP - Used by SIP voice teletphones to establish connection.
